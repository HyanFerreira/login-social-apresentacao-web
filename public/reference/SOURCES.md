## Decisões de segurança

- OAuth, sozinho, não define um protocolo de autenticação interoperável. OIDC acrescenta essa camada. Adaptadores OAuth de perfil também existem.
- ID Token não é Access Token; Refresh Token não é garantido; sessão local pertence à aplicação.
- O backend usa o ID externo, e não coincidência de e-mails, para encontrar a associação local.
- O código de aula mínimo do Socialite usa sessão e state. A referência completa acrescenta PKCE, mantendo a sessão em ambas as rotas.
- Para clientes públicos, PKCE é obrigatório conforme a recomendação atual; não coloque um client secret em app mobile ou SPA. Para clientes confidenciais, também é recomendado.
- Os exemplos de URL, IDs, e-mails e console são fictícios e identificados como ilustrações.
